ONE-TIME SETUP

Connect your Gmail

Gemini API keys cannot send Gmail. The AI Studio key is only for tutor answers and has been exposed in chat; revoke it and create a replacement. Gmail alerts need a separate Google OAuth client and your approval. Keep OAuth credentials in your local .env file—never paste secrets into chat.

  1. In Google Cloud Console, create or select a project and enable the Gmail API.
  2. Configure the OAuth consent screen. If the app is in testing mode, add your Google account as a test user.
  3. Create an OAuth client ID for a Web application. Add this exact URL as an authorized redirect URI:
  1. Copy the client ID and secret into .env in the SharpStudy folder:
GOOGLE_CLIENT_ID=your-client-id
GOOGLE_CLIENT_SECRET=your-client-secret
GOOGLE_REDIRECT_URI=

Save .env, restart the SharpStudy server, then choose Connect Gmail and approve access. Do not commit or share the credentials.

GOOGLE AI STUDIO

Connect the C# AI tutor

The key shared in chat should be revoked and replaced. Keep the new key private in the local .env file—never paste it into chat or browser code.

  1. Create a replacement API key in Google AI Studio.
  2. Open .env in the SharpStudy folder. If it doesn't exist, copy .env.example and rename the copy to .env.
  3. Add your new key and use the Gemini settings below:
LLM_API_KEY=your-new-api-key
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
      LLM_MODEL=gemini-3.8-flash

Save the file and restart SharpStudy. The app sends requests through its server; your key is not sent to the browser. Do not commit or share .env.
